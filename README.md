# Projet-Web
Carte Interactive des Décès en France

Cette application web permet de visualiser les décès en France à travers une carte interactive. En cliquant sur une région, l'utilisateur obtient des informations sur les décès dans cette zone.

Installation
Clonez le projet :

git clone https://github.com/votre-utilisateur/carte-deces-france.git
cd carte-deces-france
Ouvrez index.html dans votre navigateur pour accéder à la carte interactive.

Utilisation
Navigation : Cliquez sur une région de la carte pour voir les statistiques des décès.

Affichage : Un tableau sous la carte présente des données détaillées sur les décès par région.

Technologies
Frontend : HTML, CSS, JavaScript avec Leaflet.js pour la carte.

Base de données : MySQL 
données de l'INSEE 
https://www.data.gouv.fr/fr/datasets/fichier-des-personnes-decedees/#/resources
